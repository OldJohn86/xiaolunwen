# 路线图与 MVP 规划

> 版本：v0.2 ｜ 更新：2026-11-20

## 1. 总体节奏

| 阶段 | 时间 | 交付 | 验收标准（Exit Criteria） |
| --- | --- | --- | --- |
| **M0 探索** | 已完成 | 原始方案、产品/技术文档、交互原型 | 信息架构与阅读体验通过 5 人可用性测试 |
| **M1 最小闭环** | 4–6 周 | 诺奖专题 10 篇 + 双语精读 + 单篇讨论 | 20 名测试用户中 ≥ 60% 完整读完 1 篇并产生 1 次互动 |
| **M2 知识库成型** | 6–8 周 | 概念卡 50 张、双向链接、检索、复核工作台 | 搜索成功率 ≥ 70%；内容纠错闭环可运转 |
| **M3 增长验证** | 8–12 周 | 推荐流、创作者投稿、会员内测 | 次周留存 ≥ 25%；会员付费意愿 ≥ 3% |

## 2. M1 MVP 范围

### 必须做

- [x] 论文数据模型 + 许可证过滤（SQLite 入库流水线 + 服务端能力下发，见 `server/`）
- [x] 同源 JSON API 骨架（论文、概念、专题、讨论、许可证查询）
- [x] 前端接入 API 并展示许可证能力（API 优先，静态数据兜底）
- [ ] 诺奖专题 10 篇内容（覆盖物理、化学、生理学或医学）
- [ ] 论文详情：元数据、双语摘要、AI 结构化解读、原文/DOI 链接
- [ ] 三类内容标签与"科普简化"提示
- [ ] 讨论区（先审后发）
- [ ] 收藏与专题合集
- [ ] 搜索（标题、作者、摘要）
- [ ] AI 标识与来源段落展示
- [ ] 移动端适配

### 明确不做

- 个性化推荐算法、创作者体系、会员支付、视频拍摄、多语言、引用图谱。

### 内容清单（10 篇建议）

1. Einstein 1905 光电效应（公有领域）
2. Penzias & Wilson 1965 宇宙微波背景
3. Watson & Crick 1953 DNA 双螺旋
4. 屠呦呦等 1977 青蒿素结构
5. Higgs 1964 对称性破缺
6. Karikó & Weissman 2005 mRNA 免疫识别
7. Doudna & Charpentier 2012 CRISPR
8. Perelman 2003 庞加莱猜想（arXiv）
9. LIGO 2016 引力波探测

> 每篇入库前核对：许可证是否允许翻译/演绎/商用、元数据是否准确、原文链接是否可用。

## 3. 技术里程碑

- **第 1 周**：数据模型、许可证服务、内容录入后台。
- **第 2–3 周**：AI 流水线（解析 → 翻译 → 抽取）、人工复核工作台。
- **第 3–4 周**：前端详情页、讨论区、搜索。
- **第 5 周**：内容填充与端到端联调。
- **第 6 周**：可用性测试、修复、灰度发布。

## 4. 指标体系

**北极星**：周"读到达标"用户数 =（读完一篇解读 ∧ 展开 ≥1 个证据段落 ∧ 产生 ≥1 次互动）去重用户。

| 层级 | 指标 | M1 目标 |
| --- | --- | --- |
| 激活 | 首页 → 详情页点击率 | ≥ 35% |
| 阅读 | 详情页平均阅读时长 | ≥ 3 分钟 |
| 阅读 | 解读完成率（滚动 ≥ 80%） | ≥ 40% |
| 信任 | 溯源链接点击率 | ≥ 15% |
| 社区 | 有讨论的论文占比 | ≥ 30% |
| 留存 | 次周留存 | ≥ 20% |
| 质量 | 用户纠错率 / 复核驳回率 | 建立基线 |

## 5. 团队与预算（粗估）

| 角色 | 人数 | 说明 |
| --- | --- | --- |
| 产品 / 设计 | 1 | 兼做用户研究 |
| 全栈工程师 | 1–2 | 前端 + BFF |
| AI / 后端工程师 | 1 | 流水线、复核工具 |
| 学科编辑 | 2–3 | 内容复核，可兼职 |
| 运营 | 1 | 社区、专题 |

**主要成本**：人力 > AI 推理 > 内容版权/授权 > 基础设施。M1 阶段建议以 3–5 人小团队控制范围。

## 6. 决策检查点

- **M1 结束**：如果"读到达标率" < 20%，优先改内容形态（更长解读？更多可视化？），而不是加功能。
- **M2 结束**：如果检索使用率 < 10%，说明用户只把产品当信息流，知识库价值待验证。
- **M3 结束**：如果付费意愿 < 3%，转向机构采购（高校、中学、科普馆）而非 C 端订阅。
