# 内容许可证策略与校验器

> 版本：v0.2 ｜ 状态：规则已编码，待法务复核 ｜ 工具：[`tools/license-check/check.mjs`](../tools/license-check/check.mjs)

## 1. 为什么需要可执行的规则

原方案把"选用 OA 文献"当作版权解决方案，但 OA ≠ 可任意使用：

- **CC BY-NC**：禁止商业使用，不能进入会员、付费课程、广告变现等商业路径。
- **CC BY-ND**：禁止演绎，**全文翻译、改编、全文音频都属于演绎**。
- **出版社版权文献**：通常只允许展示元数据与摘要。
- **arXiv 预印本**：作者授予的是非独占分发许可，不必然允许翻译与改编。

因此平台不能只用"是否 OA"一个布尔值判断，而要按**具体许可证 × 具体用途**逐项校验。规则必须写进代码，而不是只写在文档里。

## 2. 操作模型

| 操作 | 含义 | 典型场景 |
| --- | --- | --- |
| `display_metadata` | 标题、作者、期刊、年份、DOI | 所有列表与详情 |
| `display_abstract` | 展示摘要（非全文） | 受限文献详情页 |
| `quote_commentary` | 短引用原文 + 评论/解读 | AI 结构化解读、争议梳理 |
| `translate_fulltext` | 全文翻译 | 双语精读 |
| `adapt_fulltext` | 全文改编 | 动画脚本、简化演示 |
| `audio_fulltext` | 全文音频 | 朗读功能 |
| `redistribute_fulltext` | 再分发全文 | 下载、导出、缓存 |
| `commercial_use` | 商业性使用 | 会员、课程、广告 |

## 3. 许可证决策矩阵

| 许可证 | 展示摘要 | 短引用评论 | 全文翻译/改编 | 再分发 | 商业使用 |
| --- | --- | --- | --- | --- | --- |
| 公有领域 / CC0 | ✓ | ✓ | ✓ | ✓ | ✓ |
| CC BY 3.0 / 4.0 | ✓ | ✓* | ✓（需署名） | ✓ | ✓ |
| CC BY-SA | ✓ | ✓* | ✓（署名 + 相同方式共享） | ✓ | ✓ |
| CC BY-NC | ✓ | ✓* | 仅非商业 | ✓ | ✗ |
| CC BY-NC-SA | ✓ | ✓* | 仅非商业（相同方式共享） | ✓ | ✗ |
| CC BY-ND | ✓ | ✓* | ✗ | ✓ | ✓ |
| CC BY-NC-ND | ✓ | ✓* | ✗ | ✓ | ✗ |
| arXiv 非独占 | ✓ | ✓* | ✗ | ✓ | ✗ |
| 出版社版权 | ✓ | 需逐篇确认 | ✗ | ✗ | ✗ |
| 未收录许可证 | ✗（fail-closed） | ✗ | ✗ | ✗ | ✗ |

\* 短引用 + 评论在所有已收录许可证下**允许但标记为需法务复核**：引用长度、转换性、是否与付费墙绑定，都会影响合理使用的判断。

## 4. 实现策略

- **fail-closed**：未收录的许可证只允许展示元数据，宁可少做也不越权。
- **商业性作为全局开关**：平台含会员与付费内容，因此默认 `commercial: true`；非商业版本（如校园公益版）可切换为 `false` 重新评估。
- **先判演绎，再判商业**：ND 内容即使非商业也不能全文翻译，避免把"非商业"误当成万能通行证。
- **署名与相同方式共享是输出要求**：校验结果同时返回 `attribution` / `shareAlike`，供前端与导出流程展示。
- **短引用与全文翻译分开**：AI 解读使用短引用 + 评论，不等同于全文翻译；全文翻译必须单独取得演绎许可。

## 5. 使用方式

```bash
# 校验内容清单
node tools/license-check/check.mjs content/license-manifest.json

# 机器可读输出（被 CI 或内容管线调用）
node tools/license-check/check.mjs content/license-manifest.json --json

# 运行规则测试
node --test tools/license-check/check.test.mjs
```

有任一项被拒绝时，CLI 退出码为 `1`，可直接接入 CI 或入库流水线：**许可证校验不通过，内容不得进入深度处理队列**。

## 6. 清单字段

```json
{
  "commercial": true,
  "papers": [
    {
      "id": "ligo-2016",
      "title": "引力波的直接探测",
      "license": "CC-BY-3.0",
      "source": "https://doi.org/...",
      "uses": ["display_metadata", "display_abstract", "translate_fulltext"]
    }
  ]
}
```

`uses` 表示平台**计划对该文献执行**的操作。校验器逐项判断并汇总拒绝项。

## 7. 已知限制与待办

1. **不是法律意见**：合理使用/合理利用、翻译权、数据库权利因司法辖区而异，上线前需逐篇核对并取得法务确认。
2. **许可证版本与附加条款**：同一篇论文可能带有出版社附加条款、embargo、S2O 等状态，需以官方页面为准。
3. **作者保留权利**：预印本与部分仓储文献的权利归作者，不能仅凭"可下载"推定可翻译。
4. **多作者混合许可**：图表、补充材料可能采用不同许可证，需要更细粒度的资产级校验。
5. **撤销与变更**：许可证变更、撤稿、更正需要触发重新校验与内容下架。
