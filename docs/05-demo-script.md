# 演示脚本（3 分钟 / 8 分钟）

> 适用场景：课程答辩、竞赛路演、项目评审。所有数字来自当前本地演示环境（59 篇论文，含本地 AI Top50 语料）。

## 演示前准备

```bash
# 重置演示数据（会清空事件、复核状态与本地评论）
node server/ingest.mjs

# 启动（API + 前端同源）
PORT=8123 node server/server.mjs
```

打开 **http://localhost:8123**。建议使用无痕窗口，保证指标从 0 开始。

可选：`XLW_REVIEW_TOKEN=your-secret` 启动，演示复核接口的令牌保护。

## 3 分钟版本

### 0:00–0:30 开场

> “我们每天刷到大量科学结论，但很少看到结论是怎么被证明的。小论文·大智慧把开放获取论文变成可溯源的知识库，而不是又一条二手科普。”

展示发现页：

- 59 篇文献、13 张概念卡、7 个专题。
- 每张卡片有期刊、年份、许可证与内容类型标签。

### 0:30–1:30 一篇论文的证据链

点击「AI 必读 Top50」→ 打开 **ResNet**：

1. 指出五段式解读：研究假设 / 实验设计 / 核心结论 / 研究局限 / 学界争议。
2. 点击任意 `§3 深度残差学习` 标签：
   - 提示“原文定位（原型示意）”，同时记录一次“展开证据”事件。
3. 滑到「许可证能力」：
   - 全文翻译、音频、改编、商业使用逐项显示允许/拒绝及原因。
4. 强调标注：**AI 辅助整理 · 待复核**，不冒充人工结论。

> “每一条解读都能回到具体章节；每个能力都受许可证约束。”

### 1:30–2:20 许可证与复核闭环

打开 **复核**：

- 33 篇待核对、26 篇需法务复核、55 篇有受限能力。
- 展示一条 UNVERIFIED 文献：
  - 受限能力清单、许可证来源、复核历史。
  - 选择新许可证 → “更新许可证并复核”会立即重算能力并写审计日志。
- 点击“导出 CSV”：导出当前筛选的编辑队列。

（演示时可不实际修改许可证，以免改变后续流程。）

### 2:20–3:00 指标与收尾

浏览一篇论文、展开一个证据、收藏后，打开 **数据**：

- 本周读到达标、打开论文人数、展开证据人数、互动人数。
- 北极星定义：同一周内「读完 + 展开证据 + 一次互动」。

> “我们不只看停留时长，而是看用户是否真的读到了证据。下一步用这套指标做 5 人可用性测试。”

## 8 分钟版本（补充）

## 预设问答

**Q：和 ChatGPT / 通用 AI 问答有什么区别？**
A：产品不是聊天机器人，而是以论文为节点的知识库：每条解读绑定原文出处与许可证；能力按许可证下发；内容进入复核队列；讨论与指标围绕单篇论文组织。

**Q：版权怎么办？**
A：只做 OA 文献与平台原创摘要/评论；NC 不做商业使用，ND 不做全文翻译改编；非 OA 只展示元数据与摘要；未知许可证 fail-closed；复核工作台保留来源证据与审计日志。

**Q：AI 幻觉怎么办？**
A：强制章节级出处；关键结论标注“待复核”；社区纠错；无法在原文定位的内容不发布。当前原型中的解读为人工/平台整理，仍未宣称已复核。

**Q：冷启动内容从哪来？**
A：先用诺奖经典与 AI Top50 自产标杆内容，再开放创作者投稿；许可证清晰的 arXiv/CC 文献优先深度处理。

**Q：商业模式是否成立？**
A：C 端会员是次要目标；更现实的是高校图书馆、中学科学课与科普机构的机构采购；AI 推理必须分层处理，避免全量深度解读。

**Q：为什么先做 Top50 而不是全学科？**
A：AI 领域引用高、讨论活跃、arXiv 版本多，适合验证“溯源 + 解读 + 讨论”的最小闭环；之后复制到诺奖专题与其他学科。
