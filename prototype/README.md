# 原型说明

零依赖静态原型，用于验证信息架构、阅读体验与交互流程。

## 运行

```bash
cd prototype
python3 -m http.server 8080
# 打开 http://localhost:8080
```

也可以直接双击 `index.html`。

## 已实现

- 卡片信息流：学科 / 内容类型筛选、搜索、排序、收藏筛选
- 论文详情：双语摘要、AI 结构化解读（假设 / 设计 / 结论 / 局限 / 争议）、原文出处标识、演示说明、思辨引导
- 许可证分级：受限文献只展示元数据与摘要，不提供 AI 精读
- 讨论区：种子评论 + 本地新增评论（localStorage）
- 收藏：localStorage 持久化
- 知识库：概念卡与论文互相链接、专题合集
- 响应式布局与键盘操作（Esc 关闭详情、Enter 打开卡片）

## 未包含

- 后端、真实 AI 流水线、账号体系、内容审核
- 真实视频 / 仿真演示
- 真实许可证校验（上线前必须逐篇核对）

## 数据说明

`js/data.js` 中所有论文元数据与解读均为演示用示例，不代表官方结论。仓库根目录的 `docs/` 中有完整的产品与技术方案。
